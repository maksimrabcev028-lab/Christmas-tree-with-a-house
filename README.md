# 🌲 Анимированная Новогодняя Ёлка и Дом на C#

Простая и уютная консольная программа на языке C#, которая демонстрирует работу с многопоточностью (`System.Threading`). Программа рисует зимний пейзаж с домом, а в параллельном фоновом потоке запускает цветную мигающую гирлянду на новогодней ёлке.

## ✨ Особенности проекта
* **ASCII-графика**: Пейзаж полностью отрисован с помощью текстовых символов в консоли.
* **Многопоточность (`System.Threading.Thread`)**: Логика анимации гирлянды полностью отделена от главного потока программы.
* **Динамическое управление курсором**: Использование `Console.SetCursorPosition` позволяет обновлять только нужные участки экрана без мерцания и полной перерисовки консоли.

## 🚀 Запуск проекта

### Требования
* Установленный [.NET SDK](https://microsoft.com) (рекомендуется .NET 6.0 или новее).
* Любая IDE (Visual Studio, JetBrains Rider, VS Code) или просто терминал.

### Запуск через консоль/терминал
1. Склонируйте репозиторий или создайте новый консольный проект
2. Замените код в файле `Program.cs` кодом программы.
3. Запустите проект
